# AI Image Caption Generator

An AI-powered web application that generates captions from images using Generative AI.

## 🚀 Features

- Upload an image and generate captions instantly.
- Simple and user-friendly interface.

## 🛠️ Tech Stack

- Python
- Flask
- PyTorch / Transformers (BLIP image captioning model)
- HTML and CSS

## ▶️ How to Run

1. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

2. Start the application:

   ```bash
   python app.py
   ```

3. Open the local URL shown in the terminal in your browser.

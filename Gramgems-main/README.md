# \# AI Image Caption Generator

# 

# An AI-powered web application that generates captions for images using Generative AI.

# 

# \## 🚀 Features

# 

# \- Upload an image and generate captions.

# \- Simple and user-friendly interface.

# 

# \## 🛠️ Tech Stack

# 

# \- Python

# \- Flask

# \- PyTorch / Transformers (BLIP image captioning model)

# \- HTML and CSS

# 

# \## ▶️ How to Run

# 

# 1\. Install the required dependencies:

# 

# &#x20;  ```bash

# &#x20;  pip install -r requirements.txt

# &#x20;  ```

# 

# 2\. Run the application:

# 

# &#x20;  ```bash

# &#x20;  python app.py

# &#x20;  ```

# 

# 3\. Open the local URL displayed in your terminal in your web browser.

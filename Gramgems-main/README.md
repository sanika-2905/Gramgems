# AI Image Caption Generator

An AI-powered web application that generates captions from images using Generative AI.

## 🚀 Features
- Upload an image and generate captions instantly
- Uses Google Gemini API
- Simple and user-friendly interface

## 🛠 Tech Stack
- Python
- Flask
- Google Gemini API
- HTML, CSS

## ▶️ How to Run
```bash
pip install -r requirements.txt
python app.py
